# Treadmill Calc - Clinical ACSM Treadmill & Cardio Calculator Suite

🔗 **Live Tool:** [https://treadmillcalc.com](https://treadmillcalc.com)

A high-precision, client-side Progressive Web App (PWA) built on official ACSM (American College of Sports Medicine) metabolic equations. Designed for runners, walkers, athletes, and fitness enthusiasts to calculate exact calorie expenditure, incline elevation gain, pace conversions, and VO2 Max scores locally inside the browser.

## 🚀 Key Features
- **Clinical ACSM Metabolic Equations:** Eliminates smartwatch overestimation by computing true gross/net calorie burn, oxygen consumption ($VO_2$), and metabolic equivalents (METs).
- **100% Client-Side Execution:** Instant, sub-millisecond calculations running entirely in browser memory with zero server roundtrips or framework bloat.
- **Offline PWA Support:** Installable on desktop and mobile devices with full offline capability via Service Workers (`sw.js`).
- **Privacy-First Architecture:** Zero personal health data or workout metrics are ever stored or transmitted to external servers.
